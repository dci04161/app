# 오픽 연습 앱 (개인용 PWA)

질문 듣기 → 녹음 → Gemini AI 피드백 → 단어장까지, 폰에서 무료로 쓰는 OPIc 말하기 연습 앱입니다.
모든 기록과 녹음은 폰 안(브라우저 저장소)에만 저장됩니다.

## 1. GitHub Pages에 올리기 (처음 한 번)

1. GitHub에 로그인 → 오른쪽 위 **+ → New repository**
2. 이름 예: `opic-practice` → **Public** 선택 → **Create repository**
3. 저장소 화면에서 **uploading an existing file** 클릭
4. 이 폴더 안의 파일·폴더를 **전부** 끌어다 놓기 (`index.html`이 저장소 맨 위에 있어야 함) → **Commit changes**
5. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**
6. 1~2분 뒤 `https://내아이디.github.io/opic-practice/` 주소가 생깁니다.

> API 키는 코드에 들어 있지 않으므로 저장소가 공개여도 안전합니다. 키는 앱 설정에서 폰에만 저장됩니다.

## 2. Gemini API 키 발급 (무료)

1. https://aistudio.google.com/apikey 접속 (Google 계정 로그인)
2. **Create API key** → 키 복사
3. 결제 계정(Billing)은 **연결하지 마세요** — 연결하면 유료로 바뀝니다.

## 3. 폰에 설치

1. 안드로이드 **크롬**으로 위 주소 접속
2. 메뉴(⋮) → **홈 화면에 추가** (또는 "앱 설치")
3. 앱 실행 → ⚙ 설정 → API 키 붙여넣기 → **저장하고 연결 확인**
4. 홈 → **서베이 설정** (실제 시험처럼 12개 이상 선택)
5. 처음 녹음할 때 **마이크 권한 허용**

## 사용법

- **실전 모의고사**: 실제 OPIc 진행 순서 그대로
  - 시작 절차: 오리엔테이션 → **Background Survey**(직업·학생·거주지 + 하위 질문, 여가·취미·운동·휴가 합계 12개 이상) → **Self Assessment**(1~6단계, 단계별 샘플 답변 듣기) → 사전 점검(소리·마이크 테스트) → 샘플 질문(채점 안 됨) → 시작
  - 본 시험: 1 자기소개 → 2~4 선택 주제 콤보 → 5~7 선택(또는 돌발) 콤보 → 7번 뒤 난이도 재조정(실제 시험에 있는 단계: 쉬운/비슷한/어려운 질문) → 8~10 돌발 콤보 → 11~13 롤플레이 → 14~15 어드밴스
  - 화면: 문항마다 **Play**를 눌러야 질문 재생, 질문 텍스트 없음, 다시 듣기는 질문이 끝난 뒤 5초 안에 1회, 답변 후 **Next**, 전체 40분 제한
  - 끝난 뒤 한꺼번에 AI 분석
- **여우오픽 기출 세트**: 1~30회를 실제 출제 순서 그대로 (난이도 5~6). 원본 정리 문서 오류(3·6·7·11회)는 질문 은행으로 보정
- **질문 출처 표시**: 교재 원문 / 여우오픽 기출(재구성 표현) / AI 보완(원문 없는 주제·롤플레이). 원문을 구하면 AI 보완 질문만 골라 교체 가능
- **예시 답변**: 연습 중 '💡 예시 답변'(녹음 중에도 펼쳐 볼 수 있음), 주제·피드백 화면의 '📘 예시 답변'. 교재 스크립트가 있으면 교재 답변, 없으면 AI 예시(IM2~IH). 롤플레이 11·12번은 통화 시작·마무리 표현도 함께 표시. 실전 모의고사 중에는 숨김
- **교재 스크립트 불러오기**: 설정 → 스크립트 파일 불러오기 → `opic_scripts.json` 선택 (한 번만). 폰 안에만 저장되며 GitHub에는 올리지 않음
- **내 서베이 기준 정리**: 고르지 않는 서베이 주제(캠핑·술집·헬스 등)와 직장·학교 질문은 제거. 공원·카페·해변은 롤플레이 관련 참고용으로만 남김(모의고사 콤보에는 안 나옴). 기출 세트에서 그런 주제가 있던 콤보·14~15번은 같은 유형 순서의 내 서베이 주제로 바꿔 출제
- **질문 음성**: 기본은 Gemini AI 음성(차분한 시험관 느낌의 여성 음성). 질문마다 처음 한 번만 만들고 폰에 저장해 두므로 두 번째부터는 무료 한도를 쓰지 않음. 답하는 동안 다음 문항 음성을 미리 준비. 설정에서 목소리 변경·들어보기 가능
- **유형·주제별 연습**: 한 문제씩 녹음 → 바로 피드백
- **피드백 내용**: 받아쓰기, 문법 교정(한국어 설명), 유창성·구성·외운 티, 예상 등급(참고), IM2~IH 추천 답변
- **모범답안**: 질문마다 IM2~IH 수준 예시 답안 (설정의 "내 정보 메모"를 반영)
- **단어 조회**: 영어 단어를 누르면 뜻·발음기호·발음 듣기, 여러 단어를 길게 눌러 선택하면 표현 조회 → 단어장 저장
- **약점**: 항목별·유형별 평균, 자주 틀리는 문법 → "약점 집중 연습"
- **백업**: 설정 → 백업 파일 내보내기 (녹음 파일 제외)

## 참고

- AI 음성을 쓸 수 없을 때(한도 초과, 모델 없음 등)는 10분 동안 자동으로 폰 내장 음성으로 읽습니다. 단어 발음·추천 답변 듣기는 한도 절약을 위해 폰 내장 음성을 씁니다.
- 폰 내장 음성이 이상하면 안드로이드 설정 → 텍스트 음성 변환 → Google 음성 엔진 영어 데이터 설치.
- 무료 한도를 넘으면 잠시 후 자동 재시도하며, 계속 실패하면 나중에 홈의 "분석 대기"에서 다시 분석할 수 있습니다.
- 무료 모델 이름이 바뀌어도 앱이 사용 가능한 모델을 자동으로 찾아 바꿉니다.
- 예상 등급은 AI가 한 문항씩 판단한 참고값이며 실제 점수와 다를 수 있습니다.
- 앱을 수정한 뒤 GitHub에 다시 올리면, 폰에서 앱을 껐다 켜면 새 버전이 적용됩니다.

## 파일 구조

```
index.html, manifest.webmanifest, sw.js   앱 기본 파일·오프라인 캐시
css/app.css                               화면 스타일
js/bank.js                                질문 은행(교재 원문·여우오픽 기출) + 롤플레이 세트
js/sets.js                                여우오픽 기출 1~30회 출제 순서
js/questions.js                           서베이 구조·AI 보완 질문·통합 조회(제거·참고 주제 설정)
js/scriptmap.js                           질문 → 교재 스크립트 항목 연결표(본문 없음)
js/scripts.js / js/views/examples.js      스크립트 불러오기·예시 답변 화면
js/exam.js                                모의고사 15문항 구성·난이도 재조정
js/views/examstart.js                     시험 시작 절차(서베이·Self Assessment·사전 점검·샘플 질문)
js/analysis.js                            AI 피드백·모범답안 프롬프트
js/gemini.js                              Gemini API 호출·재시도·모델 자동 선택
js/lookup.js                              단어 조회·단어장
js/recorder.js / tts.js / aivoice.js      녹음(WAV 변환)·폰 음성·AI 질문 음성
js/views/*                                각 화면
```

## 교재 스크립트 파일 넣기 (폰에서 한 번)

1. `opic_scripts.json` 파일을 폰으로 옮기기 (카톡 나에게 보내기, 드라이브 등)
2. 앱 ⚙ 설정 → **스크립트 파일 불러오기** → 파일 선택
3. "✓ 불러옴 · 질문 연결 288/288" 이 보이면 완료

> 이 파일은 교재 내용이라 GitHub 저장소에 함께 올리지 마세요.
